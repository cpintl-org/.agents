## 1. What this plan is (30-second version)

- CPI Bangladesh uses **16 approved program codes** (HOP, HPP, HSS, WASH, CleanEnergy,
  Education, Livelihood, RD, M&E, HIMS, Finance, Logistics, Warehouse, HR, FieldCoordination,
  MediaComms).
- The brand guide gives every CPI document **7 approved colors**, but it fixes an accent color
  for only **2** of those 16 codes. For the other **14**, a suggested grouping was written down
  in the department directory file — **marked as a proposal, not as a fact**.
- This plan exists so **leadership can say yes or no to the 14 suggestions** before the colors
  go into real templates for wide rollout. Nothing is decided until a named person approves.
- This is a **manual, human** step. No AI is involved anywhere in the decision.

## 4. How to check and where to check (step by step, no code)

1. Open the folder on GitHub (path above). Click each file to view it — GitHub shows files as
   readable pages; you do not need any software.
2. Start with [`signoff-sheet.md`](./signoff-sheet.md). Look at the table with 16 rows.
3. For each row: read the code and program name, look at the color, and check the **Status**
   column:
   - **"Guide fixes"** → the brand guide already decided; keep it.
   - **"Proposed"** → this is the suggestion leadership must approve or change.
4. Mark your decision in the last two columns (☐ Keep / ☐ Change). Add one short note if you
   change something — one line is enough.
5. When you are satisfied the sheet is correct, tell the helper "the plan is approved" (or send
   the sheet back with changes). The helper records the result in `human-approval.yaml`.

That is the whole review: **read the sheet, tick the boxes, say yes or tell us what to change.**

## 7. Suggestions (based on the data, not guesses)

1. **You only need to decide 14 of 16.** WASH and CleanEnergy are fixed by the guide. The
   sheet marks them so nobody wastes time re-deciding them.
2. **Decide by theme, not by row.** The 14 proposals are 4 groups (a theme, not 14 separate
   questions). Decide each theme once, then adjust individual codes only if needed.
3. **Watch the two purples.** Both are approved: `#41273B` (Cross-Program) and `#615E9B` (RD)
   look similar on screen. The proposal uses each in its guide-intended job (table/panel color
   vs chart color). If leadership wants clearer separation, swapping one of them is easy.
4. **Keep the "proposed" label honest.** The department directory file itself says the
   14 mappings are not stated in the guide PDF. Do not let a template print these colors as
   "official" until leadership signs this sheet.
5. **One decision per theme, one sheet back.** Send back either "all 14 approved" or the sheet
   with only the changed rows marked — that is enough to finalize.
